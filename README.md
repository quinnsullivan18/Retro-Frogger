# Frogger Game

A small Frogger-inspired game written in C++ with Win32 and Direct2D.

## About

I created this project for my freshman-year college computer science final. It was my introduction to game development, and an opportunity to build a simple game from the ground up.

## Playing

- Press **Space** or click to start.
- Use **WASD** or the **arrow keys** to move the frog.
- Guide the frog across the road and river to the safe spots.

## Build and run

This is a Windows Visual Studio C++ project. Open [`Frogger Game.sln`](./Frogger%20Game.sln), select a configuration such as **Debug | x64**, then build and run the solution. The project copies its PNG assets beside the built executable.

# Retro Frogger

A simple remake of the classic *Frogger* arcade game, written quite a while ago in **C++ using the Win32 API**.

---

## Overview
This project recreates the basic gameplay of the original Frogger — guide your frog safely across lanes of traffic and a river to reach the goal.

- Built with **C++ and WinAPI (Windows only)**
- Contains **a single playable level**
- After winning, you can **choose to replay or quit**
- Features basic graphics in the project folder
